ابن حميدو - ملفات الموقع

طريقة الرفع:
1) فك ضغط الملف.
2) افتح مستودع GitHub الجديد.
3) اضغط Add file ثم Upload files.
4) ارفع index.html و README.txt إلى المجلد الرئيسي (Root).
5) من Settings > Pages اختر Deploy from a branch ثم main و /(root) ثم Save.

بعدها انتظر نشر الموقع وافتح رابط GitHub Pages.

ملاحظات:
- الموقع صفحة واحدة متجاوبة مع الموبايل والكمبيوتر.
- الصور المستخدمة صور طعام خارجية من Unsplash وتحتاج إنترنت للظهور.
- أرقام التواصل والموقع مضافة في قسم التواصل.
- راجع الأسعار وتفاصيل الصواني قبل النشر النهائي.

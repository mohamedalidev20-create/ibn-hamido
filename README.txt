ابن حميدو — موقع طلبات تفاعلي

المحتويات:
- index.html: الموقع كامل في ملف واحد.
- تصميم متجاوب للموبايل والكمبيوتر.
- صور منفصلة لكل صنف (روابط صور خارجية).
- بحث وتصنيفات.
- سلة تفاعلية: إضافة، حذف، زيادة وتقليل الكمية، حساب الإجمالي.
- حفظ السلة على نفس الجهاز باستخدام localStorage.
- إرسال تفاصيل الطلب والإجمالي إلى واتساب المطعم.
- لا يطلب الموقع عنوان العميل أو موقعه.

طريقة الرفع:
1. فك ضغط ZIP.
2. ارفع index.html إلى Root في المستودع الجديد.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.

مهم قبل النشر:
- راجع الأسعار والوصف مع المطعم.
- الصور صور توضيحية خارجية، وتحتاج إنترنت للتحميل. يُفضّل استبدالها بصور الأطباق الأصلية للمطعم عند توفرها.
